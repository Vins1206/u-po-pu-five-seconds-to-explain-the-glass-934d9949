## What it does

`main.py` writes exactly one sentence — the excuse a house cat gives in the
five seconds after sweeping a glass off the table — to `/output/entry.txt`.
No apology, no confession: the glass was squatting in the cat's sunbeam,
paying no rent, and staring at it, so the cat evicted it and the floor
handled the paperwork.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

Python 3 standard library only, no dependencies. The output is a single
sentence of 121 characters, well within the 200-character gate.
